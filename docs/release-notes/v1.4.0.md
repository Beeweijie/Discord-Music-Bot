# v1.4.0 · 喵酱语音点歌与 playskip

新增可选的本地中文语音点歌：说「喵酱喵酱」，听到「我在喵」后再说指令。支持一次说完唤醒词和指令。

## 新功能

- SenseVoiceSmall / FunASR 本地识别，配合可选的读音唤醒模型。音频只在内存中处理，不保存录音或普通聊天转写。
- 固定的可莉中文角色合成音色回复；播歌时短暂降低音乐音量，暂停时回复不推进歌曲进度。模型及音色来源见 [说明](https://github.com/Beeweijie/Discord-Music-Bot/blob/v1.4.0/docs/voice-replies.md)。
- 同音歌名联想，例如「与爱」→「雨爱」，结合队列、历史、个人收藏和歌单筛选音乐结果；不确定时提供最多三个候选。
- 语音「播放＋歌名」加入队首并立即切歌；「加入＋歌名」只加入队尾，空闲时也不会自动播放。「播放歌单」继续当前队列。
- 新增 `!playskip 歌名或链接`、`/playskip`，支持原有单曲、歌单和自动补全；`playtop` 仍只加到队首而不打断当前曲目。搜索失败不切歌，其余队列保留。
- 说「闭嘴／取消／安静」结束本次监听、取消候选和停止当前回复，音乐继续；文字兜底为 `!voice quiet` / `/voice quiet`。
- 重新唤醒可退出旧候选和取消旧搜索。每次唤醒最多提示一次「没听清」，超时安静退出；回复和搜索期间继续接收新唤醒、取消和后续指令。
- `!voice test` / `/voice test`：主动开启后，仅显示发起者接下来 30 秒、最多三段诊断转写。前缀结果显示在频道，斜线结果仅本人可见。

## 安装和升级

普通音乐功能直接升级即可，语音默认关闭。原 `!update` 支持本发布包；升级后使用 `/resume` 恢复保存的队列。

开启语音需先在项目根目录执行：

```text
python scripts/install_voice.py
```

安装器会选择 Bot 当前使用的更新环境或 `.venv`。随后按 [README](https://github.com/Beeweijie/Discord-Music-Bot/blob/v1.4.0/README.md) 单独下载 SenseVoice 模型（建议再安装读音唤醒模型），在 `.env` 设置 `VOICE_COMMANDS_ENABLED=true` 和 `VOICE_ASR_LANGUAGE=zh`，重启后通过 `/join` 加入语音频道。Release 不包含大型识别模型。

从旧更新器升级时，如果此前自行开启过语音，请在升级后重新运行上述安装器，再重启。v1.4.0 起的更新准备流程会在语音开启时安装可选依赖。设置、用户数据、模型与保存的队列沿用现有保护和回滚机制。

## 验证与已知限制

发布工作流在 Linux 和 Windows 安装可选依赖并运行完整回归；Linux 同时验证仅安装基础依赖的运行方式。测试覆盖排队与立即切歌、暂停保护、候选取消、慢搜索撤销、有限重试、同频道权限、包清单、更新与回滚。

发布前分别运行 246 项回归：Linux 通过（3 项平台专用测试跳过），Windows 通过（2 项平台专用测试跳过）。另以原版 v1.3.0 更新器实际解压新 ZIP，并逐字节核对五句内嵌回复与原始音频一致；两个模型下载地址均返回成功。

真人测试已成功唤醒、切歌并播放杨丞琳《雨爱》，仍出现过错误转写和歌名版本后缀识别不准。使用耳机、补充歌手和选择候选有助于消歧；识别准确率仍需实际使用验证。
